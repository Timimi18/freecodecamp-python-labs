# freeCodeCamp Python Independent Labs Archive

This repository preserves the independent coding labs and structural assignments executed throughout my freeCodeCamp Python training track. Unlike guided modules, these labs required parsing strict technical specifications and building matching logic from scratch to pass integrated test suites.

## 🧠 Computational Paradigms Demonstrated
* **Test-Driven Problem Solving:** Deconstructing complex technical error messages to realign edge-case execution paths.
* **Classical Algorithms & Data Structures:** Developing foundational data management arrays, sorting profiles, binary search variants, and graph trackers.
* **Defensive Engineering Type Checking:** Implementing verification layers to catch data type anomalies before background execution breaks down.

## 📂 Complete Labs Directory (17 Total)

### 🧩 Structural Logic & OOP Foundations (Labs 01 - 07)
* **`01_travel_weather_planner.py`** - Evaluates travel feasibility based on distance constraints, weather conditions, and transport accessibility.
* **`02_discount_calculator.py`** - A defensive pricing function that validates numerical types and boundaries before applying a percentage markdown.
* **`03_rpg_character_creator.py`** - Validates custom player attributes and maps point allocation metrics into a dynamic ASCII data display block.
* **`04_number_pattern_generator.py`** - Generates space-separated sequential numeric structures using loops with strict type assertions.
* **`05_isbn_validator.py`** - Processes string entries to validate ISBN-10 and ISBN-13 checksum strings via custom Try-Except filters.
* **`06_planet_class_model.py`** - Implements structured blueprint states using base data verification rules and object string representations.
* **`07_game_character_stats.py`** - Demonstrates data encapsulation using Python property setters and getters to defend state ceilings.

### 📐 Advanced Architecture & Core Algorithms (Labs 08 - 17)
* **`08_player_abc_interface.py`** - Implements enforcement layers using Python Abstract Base Classes (`abc`) to manage polymorphically inherited subclass movement patterns.
* **`09_recursive_range_generator.py`** - Uses clean procedural call-stacks to construct incremental list arrays recursively without loop expressions.
* **`10_square_root_bisection.py`** - Employs binary boundary convergence (Bisection Method) to approximate numerical square roots down to minor tolerances.
* **`11_quicksort_integer_array.py`** - Uses divide-and-conquer logic arrays to build out low-overhead Quicksort array sorting rules.
* **`12_selection_sort_array.py`** - Loops cleanly over collection fields using sorting methodologies to isolate minimum indexes and minimize data swappings.
* **`13_luhn_checksum_validator.py`** - Uses structural modular math components via the Luhn validation algorithm to evaluate credit card legitimacy markers.
* **`14_adjacency_list_to_matrix.py`** - Parses internal dictionary-mapped connectivity schemas and converts them into explicit 2D adjacency matrix grids.
* **`15_dfs_graph_traversal.py`** - Traverses multi-directional graph spaces systematically using tracking matrices and custom execution call-stacks.
* **`16_n_queens_backtracking.py`** - Employs a last-in-first-out optimization matrix stack to evaluate non-conflicting column coordinates for the N-Queens challenge.
* **`17_fibonacci_dynamic_tabulation.py`** - Solves the calculation profile of high-index Fibonacci integers smoothly through dynamic programming memory tables.
